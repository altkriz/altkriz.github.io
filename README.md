### About Me

I'm a **Software Engineer** and **Creative Technologist** based in New Delhi. With a background in **Electronics Engineering** and currently pursuing my **Master's in Computer Applications** at **Jamia Hamdard University**, I blend hardware-level understanding with modern web development.

I build tools that are fast, accessible, and useful — from **IoT systems** on Raspberry Pi to **vibecoding platforms** like KrizVibe Editor.

- 🎓 **Education:** MCA (Jamia Hamdard) | BCA (IGNOU) | Diploma in Electronics (Ambedkar Institute)
- 🛠️ **Focus:** Full-Stack Development, IoT, UX Engineering, and Performance Optimization.
- 🚀 **Current Project:** Building **[KrizVibe Editor](https://altkriz.github.io/htmleditor)** — a vibecoding platform for creative developers.
- 🌍 **Languages:** English, Urdu, Arabic.
